# Notebooks

`01_data_audit.ipynb` is the executed, reproducible Gate 2 audit notebook. It
reads repository-relative public audit tables and saves a repository-relative
coverage figure. Do not store raw corpus data or notebook checkpoints in
version control.

`02_transparent_metrics_and_keyness.ipynb` is the executed Gate 3 reviewer
readout. It reads generated metrics and keyness artifacts and saves the Gate 3
figures under `reports/figures/`.
